Testing whether credit model explanations hold up

Challenge
UK GDPR Article 22 and FCA Consumer Duty require lenders to explain automated credit decisions. An explanation is only defensible if it stays stable when the model is retrained.
Approach
Built SSEF, a SHAP stability framework. Trained Random Forest and XGBoost on 150,000 loan records and ran 50 perturbation tests per model.
Decision
XGBoost showed perfect agreement under refitting. A validation step I added proved the 25 models were identical, so I reported a configuration artefact instead of a false result.
Outcome
Random Forest stayed above 0.99 on Kendall's W. XGBoost fell to 0.973 under resampling. Stability depends on the test you run.

Web application assessment and ransomware analysis

Challenge
Assess a vulnerable web application and an unknown Linux binary, then advise a non-specialist owner what to fix first.
Approach
Scanned with OWASP ZAP and Nikto and ranked six vulnerabilities by CWE and CVE, led by SQL injection, remote file inclusion and path traversal.
Decision
Ran authenticated scans as well as unauthenticated ones. ZAP alerts rose from 11 to 37 and Nikto findings from 3 to 16.
Outcome
Identified the binary as AES-GCM ransomware with a hardcoded key, so victims recover files without paying. Wrote a YARA rule to detect it.

Challenge
